APPLY FILE I/O MIGRATION (Lab 9 INLINE STYLE)

I have an existing CS111 Java project that currently uses two separate
utility classes for file handling: WriteText.java and ReadText.java.
Migrate the project to keep file I/O INSIDE Main as Lab 9 does.

  a) DELETE the two utility files completely:
       <package>/WriteText.java   → DELETE
       <package>/ReadText.java    → DELETE

  b) ADD two static void methods at the BOTTOM of Main.java
     (just above the closing } of the Main class):

       /
        * Saves all <items> to the text file.
        */
       public static void writeText() {
           try {
               Formatter output = new Formatter("<filename>.txt");
               if (system.<getMainList>().isEmpty()) {
                   System.out.println("No <items> yet.");
               } else {
                   for (<MainItemType> ele : system.<getMainList>()) {
                       output.format(ele.toString() + "\n");
                       output.format("\n---------------------------------------------\n");
                   }
                   System.out.println("All <items> saved to the text file <filename>.txt");
               }
               output.close();
           } catch (SecurityException ex) {
               System.err.println("You do not have write access to this file.");
               System.err.println(ex);
           } catch (FileNotFoundException ex) {
               System.err.println("Error opening or creating file.");
               System.err.println(ex);
           }
       }

       /
        * Reads the text file line by line and prints each line.
        */
       public static void readText() {
           try {
               Scanner fileIn = new Scanner(new File("<filename>.txt"));
               while (fileIn.hasNextLine()) {
                   System.out.println(fileIn.nextLine());
               }
               fileIn.close();
           } catch (FileNotFoundException ex) {
               System.err.println("Error opening or creating file.");
               System.err.println(ex);
           } catch (NoSuchElementException ex) {
               System.err.println("File improperly formed.");
               System.err.println(ex);
           } catch (IllegalStateException ex) {
               System.err.println("Error reading from file.");
               System.err.println(ex);
           }
       }

       <MainItemType> → the saved-list element type (e.g. ParkingSpot, Member)
