THE DEFAULT CONSTRUCTOR
▪By default, the compiler provides a default constructor with no 
parameters in any class that does not explicitly include a 
constructor. 
▪If  you declare any constructors for a class, the Java compiler will not create a 
default constructor for that class
▪With the default constructor, its instance variables are initialized to 
their default values.
