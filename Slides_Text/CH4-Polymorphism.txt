Method Matching (Static binding)
The compiler decides which method signature to use
Based on:
Method name
Number of parameters
Parameter types
Happens at compile time
Method matching (compile-time) is often called static binding

When you treat a variable of the superclass as an instance of the subclass
From superclass → subclass
Must be done manually
Can cause a runtime error
Explicit casting does NOT change the object type, only the reference type.
